# Knowledge — décisions & savoir accumulé

Ce dossier conserve, d'une session à l'autre, les **décisions, raisonnements et contraintes**
non déductibles du code : préférences de Nicolas, justifications nutritionnelles, arbitrages.

> À remplir à chaque fin de session (voir le réflexe dans [../CLAUDE.md](../CLAUDE.md)).
> À consulter en début de session pour ne pas reposer de questions déjà tranchées.
